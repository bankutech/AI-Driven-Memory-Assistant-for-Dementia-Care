# 🧠 AI-Driven Memory Assistant for Dementia Care

An innovative, full-stack application designed to support dementia patients and their caretakers by providing AI-assisted memory recall, daily activity tracking, and intelligent reminders.

## 🚀 Tech Stack
- **Frontend:** Next.js, React
- **Backend:** Node.js, Express, Prisma ORM
- **AI/ML Service:** Python (FastAPI/Flask)
- **Database:** PostgreSQL / SQL

## ✨ Key Features
- **Intelligent Memory Recall:** Uses AI to help patients recall important memories or daily routines.
- **Microservices Architecture:** Distinct services for the frontend UI, main backend logic, and specialized AI processing.
- **Responsive UI:** Built with modern React and Next.js for a seamless user experience across devices.
